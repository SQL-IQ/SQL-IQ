Evaluation

Detailed description of metrics, computation formulas, and the evaluation environment used across all 7 tasks in SQL-IQ.

Metrics by Task

Each task uses a metric appropriate to its nature. All scores are reported as percentages (0–100).

Task Metric Description
Text-to-SQL Execution Accuracy (EX) Whether the predicted SQL produces the same result as the gold SQL on the test database
Conversational SQL Execution Accuracy (EX) Same as Text-to-SQL but evaluated within multi-turn context
SQL Judge Accuracy Whether the model selects the correct SQL from two candidates
SQL Equivalence Judge Accuracy Whether the model correctly determines if two SQL queries are semantically equivalent
SQL Error Classification Accuracy Whether the model correctly identifies the error type in a buggy SQL query
SQL Debugging† Reward Score BIRD-CRITIC's composite score measuring debugging quality
SQL Translation Execution Accuracy (EX) Whether the translated SQL produces correct results on the target dialect's engine

† SQL Debugging is evaluated via BIRD-CRITIC. See their documentation for detailed metric definitions.

Metric Formulas

Execution Accuracy (EX)

Used for Text-to-SQL, Conversational SQL, and SQL Translation. Compares the execution results of the predicted SQL against the gold SQL on the evaluation database.

EX = (1/N) × Σᵢ 𝟙[ exec(pred_i) = exec(gold_i) ]
  • N — Total number of test samples
  • exec(q) — The result set obtained by executing query q on the test database
  • 𝟙[·] — Indicator function (1 if condition holds, 0 otherwise)

Accuracy

Used for SQL Judge, SQL Equivalence Judge, and SQL Error Classification. Measures the proportion of correct predictions.

Accuracy = (1/N) × Σᵢ 𝟙[ pred_i = label_i ]
  • pred_i — Model's predicted label/choice for sample i
  • label_i — Ground truth label for sample i

Overall Score

The Overall score is the unweighted arithmetic mean of all submitted task scores. If a model has not been evaluated on some tasks, the Overall is computed only over the tasks with available scores.

Overall = (1/|T|) × Σ_{t∈T} score_t
  • T — Set of tasks for which scores are available (|T| ≤ 7)
  • score_t — The score (0–100) for task t
  • For a complete submission (all 7 tasks), Overall is the simple 7-task average

Execution Details

Result Comparison

For execution accuracy, we compare result sets as unordered multi-sets unless the gold SQL contains an explicit ORDER BY clause, in which case the result is compared as an ordered list.

Timeout Handling

SQL execution is subject to a 30-second timeout. Queries exceeding this limit are marked as incorrect. This prevents infinite loops and extremely inefficient queries from stalling evaluation.

SQL Translation Scoring

For SQL Translation, the final score is the macro-average across all 5 target dialects. Each dialect contributes equally to the composite score, regardless of the number of test samples per dialect.

Error Tolerance

Predictions that cause runtime errors (syntax errors, type mismatches, etc.) are counted as incorrect. No partial credit is given for partially correct results.
